# 📊 SQL Data Analytics Project

A comprehensive SQL project focused on data exploration, analytics, and reporting using a sales data warehouse. The project demonstrates how SQL can be used to explore data, calculate business metrics, identify trends, segment customers, and create analytical reports.

## 📌 Project Overview

The project is based on a sales data warehouse containing customer, product, and sales information.

The main goal is to analyze the data and transform it into meaningful business insights using SQL.

The analysis covers:

- Database and data exploration
- Dimensions exploration
- KPIs and business metrics
- Sales and customer analysis
- Time-based analysis
- Ranking analysis
- Cumulative analysis
- Performance analysis
- Part-to-whole analysis
- Customer segmentation
- Customer and product reporting

## 🔎 Key Analysis Areas

### Sales Analysis

Analysis of sales performance, revenue, quantity, orders, and other key business metrics.

### Customer Analysis

Analysis of customer behavior, purchasing activity, value, and segmentation.

### Product Analysis

Analysis of product performance, sales contribution, quantity sold, and customer reach.

### Time-Based Analysis

Analysis of sales and performance across different time periods to identify trends and changes.

### Advanced SQL Analysis

The project uses various SQL techniques to answer analytical questions, including:

- Aggregations
- Joins
- CTEs
- Subqueries
- Window functions
- Ranking
- Running totals
- Date calculations
- Conditional logic
- Segmentation
